# ModelsFind Theme

> Not a Core V1 theme. This package carries executable code (an application framework
> or a runtime bundle); charter §3 defines themes as declarative data, and §7 places
> packages like this outside V1. It is retained in the tree and is not supported by
> Core V1.

ModelsFind is an embedded storefront theme for premium model directories and booking-led portfolio sites:

- editorial profile discovery
- private collection and access cues
- premium booking request flows
- dark catalog layouts with restrained hierarchy
- storefront-ready account and product routes

It is designed for operators who want a refined model-booking presentation while still keeping Jiffoo's storefront and ordering foundations available.
