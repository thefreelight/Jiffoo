# Imagic Studio

Embedded renderer package for the `imagic-studio` official storefront theme.

Canonical theme-pack source lives in:

- [official theme package](https://github.com/thefreelight/jiffoo-extensions-official/tree/master/packages/shop-themes/imagic-studio)

This mirror exists so the Shop runtime can render the storefront immediately while the downloadable theme-pack remains owned by the official extensions repository.
