# Bokmoo Theme

> Not a Core V1 theme. This package carries executable code (an application framework
> or a runtime bundle); charter §3 defines themes as declarative data, and §7 places
> packages like this outside V1. It is retained in the tree and is not supported by
> Core V1.

Bokmoo is an embedded official storefront theme for premium travel connectivity:

- destination eSIM plans
- regional travel passes
- instant QR delivery
- setup-first onboarding
- premium black-and-gold brand presentation

It is designed for official Bokmoo storefronts that should feel more like a travel welcome kit than a generic telecom shop.
