# Jiffoo Default Storefront Theme

The built-in theme is the zero-plugin storefront fallback. It keeps the
customer journey focused on product discovery, cart, checkout, orders, and
account management.

The default theme does not contain product-site, installer, deployment, or
documentation landing-page archetypes. Product websites belong in their own
application or purpose-built theme instead of being embedded in every store.

## Configuration

The default theme accepts brand, layout, feature, and storefront settings. The
`storefront` archetype is the only homepage mode rendered by this package.
Other purpose-built theme packages may define their own modes.

## Development

```bash
pnpm install
pnpm type-check
```
